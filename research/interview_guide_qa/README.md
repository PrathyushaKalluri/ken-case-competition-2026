# Interview Guide QA — plain-language script, tested against 3 personas

This folder is a companion to the team's existing `interview_guide.md` (the compact, per-stakeholder reference card, including technicians and the landlord addendum). What's here is a different, complementary artifact: a single **40-minute, plain-language, word-for-word household script**, deliberately written for a non-technical, non-English-fluent respondent (the "housewife/common person" bar), and pressure-tested with simulated interviews before being finalized.

**Final deliverable**: `output/docx/Ken_2026_Household_Interview_Guide.docx` — the polished Word document, including the decision-maker map, the testing summary, and the appendix personas below.

## Files in this folder

- `Household_Interview_Guide_Plain_Language_v2.md` — the tested, final version of the plain-language script (source markdown for the Word doc).
- `Test_Personas.md` — the three household personas used to pressure-test the guide, with ground-truth facts each persona only reveals if well-probed.
- `Simulation_1_3pct_household.md`, `Simulation_2_1pct_household.md`, `Simulation_3_renter_household.md` — full transcripts and critiques from three independent AI-simulated interviews (one per persona), each identifying specific wording/structural fixes that are now folded into v2. Kept as process evidence — the competition's own Q2 criteria explicitly credit "chat logs, including logs of you working the problem through with an AI."

## Why this exists alongside `interview_guide.md`

`interview_guide.md` is optimized for the interviewer's own quick reference across all 8 stakeholders (households + technicians + landlord). This guide is optimized for a first read-through by someone less familiar with the project, in full sentences, with a fixed 40-minute time budget, explicit non-leading discipline spelled out per section, and a decision-maker framework (coordinator / owner / approver / payer / access-granter) synthesized from what the three test personas revealed. Use whichever fits the moment — they draw on the same underlying question set and don't contradict each other.
